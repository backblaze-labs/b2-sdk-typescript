# Completed exec-plans

Archive of shipped plans, kept for provenance — how a piece of work was actually
sequenced and what it touched. Moved here from [`../active/`](../active/) when done.

**Convention**

- Keep the original `NNNN-short-slug.md` name.
- Add a closing line: the resolving PR(s) and the date shipped.
- Don't edit the history to look tidier than it was — the value is the real path.

Durable *decisions* (not the step-by-step) belong in
[`../../design-docs/`](../../design-docs/) as ADRs.
